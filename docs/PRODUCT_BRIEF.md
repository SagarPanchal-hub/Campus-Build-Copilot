# Campus Build Copilot

## Vision

Help college students move from vague ideas to realistic, testable prototypes.

## Problem

Students often have ideas but struggle to:
- define the actual problem
- identify the target user
- challenge assumptions
- choose a realistic MVP
- decide what to build first
- turn an idea into a technical plan
- explain their idea clearly

## Target Users

College students with beginner-to-intermediate technical ability.

## Core Workflow

Student Idea
→ Problem Definition
→ Target User
→ Assumptions
→ Solution Options
→ MVP
→ Technical Plan
→ Validation
→ Challenge My Idea
→ 7-Day Build Plan
→ Demo Script

## Core Features

1. Idea Input
2. Analyze Idea
3. Challenge My Idea
4. MVP Generator
5. Technical Build Plan
6. Validation Plan
7. 7-Day Build Plan
8. Demo Script
9. Human Check

## Non-Goals

The product should not:
- guarantee that an idea will succeed
- fabricate statistics
- fabricate user research
- pretend that real-world validation has happened
- replace human judgment

## Success Criteria

A student should be able to enter an unclear idea and leave with:
- a clearer problem
- target users
- key assumptions
- a realistic MVP
- risks to test
- a practical build sequence
- a demo plan
